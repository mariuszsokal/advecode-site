About

A studio built on curiosity

Advecode was founded in 2018 by Mariusz Sokal, but the code goes back to 2012 — years spent building websites, game-server plugins, and running multiplayer game servers, long before any of it was a job. That hands-on era turned into professional experience building and operating production web platforms for companies of different sizes. Today Advecode stays small by design: every project gets senior attention, honest communication, and code the next person can actually maintain.
